# Module 2: Visual + Text Embedding Generation & Persistent Vector Storage

Part of the **Fully Local, Offline-at-Runtime Multimodal Video Retrieval System**.

Module 2 ingests the timestamped frames, transcripts, and master metadata generated by **Module 1**, computes localized dense vector embeddings across visual and textual modalities, and maintains an offline persistent vector store with atomic ACID guarantees.

---

## Key Architectural Principles

1. **Strictly Local & Offline at Runtime**:
   - Zero cloud APIs (no OpenAI, Gemini, Groq, Pinecone, or Weaviate).
   - Once models are cached, all index and query operations execute with `HF_HUB_OFFLINE=1` and `local_files_only=True`.
2. **Modality Isolation & Score Integrity**:
   - **Visual Modality**: Google SigLIP/SigLIP2 (`google/siglip2-base-patch16-224`, 768 dimensions). Frames are encoded via image features; textual queries are projected into the visual space via SigLIP's text tower.
   - **Text Modality**: SentenceTransformers (`sentence-transformers/all-MiniLM-L6-v2`, 384 dimensions) for speech transcripts.
   - **CRITICAL**: Visual and text scores originate from distinct models and different cosine distributions. **Do NOT merge raw visual and text scores directly.** Downstream modules (Module 3) must use **Reciprocal Rank Fusion (RRF)** or per-modality min-max normalization.
3. **SQLite as the Source of Truth with Auto-Rebuilding FAISS**:
   - Vector metadata, timestamps, and full float32 embeddings (stored as raw BLOBs) reside in SQLite (`output/vector_db/metadata.db`).
   - FAISS `IndexIDMap2(IndexFlatIP)` indices act as rebuildable acceleration caches. On any detected discrepancy, corruption, or missing index file, FAISS is autonomously rebuilt from SQLite BLOBs without calling any neural network models.
4. **Deterministic Timestamps & Zero Redundancy**:
   - Timestamps are never derived from vector sequence positions or indices. They are copied verbatim from Module 1 (`timestamp_seconds` for frames, `start_time`/`end_time` for speech).
   - Frame and segment content hashes prevent redundant re-embedding. Re-running the indexer is completely idempotent.
5. **Path Re-anchoring**:
   - Absolute paths recorded by Module 1 on another machine or path structure are dynamically re-anchored to the local runtime workspace without editing Module 1 outputs.

## Installation & Setup

All dependencies install cleanly in Python 3.13:

```bash
cd "Final Project/module2"
pip install -r requirements.txt
```

### 1. One-Time Model Download (Internet Required)

Run the one-time model caching command:

```bash
python main.py download-models
```

This caches `google/siglip2-base-patch16-224` and `sentence-transformers/all-MiniLM-L6-v2` locally in the HuggingFace cache. All subsequent indexing and query operations will run completely offline.

## CLI Usage

### Indexing Module 1 Outputs

```bash
# Index all completed Module 1 videos incrementally
python main.py index --all

# Index a single video by ID
python main.py index --video-id vid_d3147dcb7284cc89

# Force re-indexing of all videos (re-embeds items)
python main.py index --all --force-reindex

# Rebuild vector database from scratch (wipes DB + FAISS and re-embeds)
python main.py index --rebuild

# Prune entries whose Module 1 metadata JSON no longer exists
python main.py index --all --prune-missing

# Index visual frames only
python main.py index --all --visual-only

# Index speech transcripts only
python main.py index --all --text-only
```

### Validating Database & Vector Index Integrity

```bash
python main.py validate
```

Exits with `0` on PASS, or `1` on FAIL. Checks:
- Bidirectional vector ID resolution between FAISS and SQLite.
- Dimension consistency and vector count equality.
- Absence of orphan vectors and duplicate keys.
- Timestamp validity (`timestamp >= 0`, `start <= end`).

### Querying & Searching

```bash
# Search both visual frames and speech transcripts
python main.py search "presentation slide on multimodal retrieval" --top-k 5

# Search visual modality only
python main.py search "diagram of pipeline architecture" --modality visual --top-k 5

# Search text speech transcript only
python main.py search "speech recognition" --modality text --top-k 5

# Filter search to a specific video
python main.py search "introduction" --video-id vid_d3147dcb7284cc89
```

### Inspecting Statistics

```bash
python main.py stats
```

## How Module 3 (Retrieval & Fusion UI) Uses Module 2

Module 3 imports `VideoIndex` from `embedding_store.retrieval`:

```python
from embedding_store.retrieval import VideoIndex

# 1. Open the video index once during service / app startup
index = VideoIndex.open()

# 2. Query visual and text modalities
query_str = "student discussing neural network architectures"
visual_hits = index.search_visual(query_str, top_k=10)
text_hits = index.search_text(query_str, top_k=10)

# 3. Fuse rankings in Module 3 using Reciprocal Rank Fusion (RRF)
# DO NOT add raw visual and text cosine scores together!
def rrf(visual_results, text_results, k=60):
    scores = {}
    for rank, h in enumerate(visual_results, 1):
        key = (h["video_id"], round(h["timestamp_seconds"], 1))
        scores[key] = scores.get(key, 0.0) + (1.0 / (k + rank))
    for rank, h in enumerate(text_results, 1):
        key = (h["video_id"], round(h["start_timestamp"], 1))
        scores[key] = scores.get(key, 0.0) + (1.0 / (k + rank))
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)

# 4. Cross-modal temporal linking
# Given a visual hit at timestamp 14.0s, find spoken audio around it:
surrounding_speech = index.get_segments_in_window(
    video_id="vid_d3147dcb7284cc89",
    start=10.0,
    end=18.0,
)

# Given a speech segment hit at [4.0s - 7.0s], find representative frames in that window:
matching_frames = index.get_frames_in_window(
    video_id="vid_d3147dcb7284cc89",
    start=4.0,
    end=7.0,
)

# 5. Close index on shutdown
index.close()
```
